# AIvor Scenarios

Place scenario background images and Remotion composition helpers here.

## Built-in Scenarios

### studio
Dark studio with warm golden key light, BLKOUT branding visible.
Best for: Formal announcements, newsletter intros, official messages.
Background: Pure black with subtle gold gradient from top-left.

### office
Warm, book-lined study with leather armchair and desk lamp. 1940s aesthetic.
Best for: Advice content, wellbeing messages, personal stories.
Background: Dark wood tones, warm amber lighting, out-of-focus bookshelves.

### london
London landmark in soft focus behind AIvor.
Best for: Community updates, event invitations, local news.
Background: Tower Bridge / Southbank at golden hour, soft bokeh.

### event
Stage or podium with BLKOUT event branding and gold lighting.
Best for: Event promos, calls to action, celebration announcements.
Background: Stage lighting, gold spots, BLKOUT banner visible.

### abstract
Animated sovereignty gold particles flowing on black.
Best for: Social media clips, short-form content, musical moments.
Background: Remotion-generated particle animation (no image needed).

### custom
User-provided image or AI-generated via blkout-image-gen skill.
Best for: Anything specific the user needs.

## Generating Scenario Backgrounds

Use the blkout-image-gen skill:
```
/blkout-image-gen warm book-lined study with 1940s aesthetic, leather armchair, desk lamp, dark wood tones --type web --quality balanced --size 2K --aspect 9:16
```
